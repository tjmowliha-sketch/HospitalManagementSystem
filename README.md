# 📊 PROJECT OVERVIEW

This Hospital Management System helps hospitals manage core operations digitally.
It includes modules for:

▪ Patient registration and management
▪ Doctor management
▪ Appointment scheduling
▪ Billing system
▪ Medical history tracking

The system ensures smooth data handling using MySQL and a user-friendly Java Swing interface.
